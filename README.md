# Parcel Flow Sandbox

This repository contains a deliberately small, fully synthetic parcel-tracking
application. Its pull requests are designed to exercise code-review interfaces
with varied file shapes, dependency relationships, renames, and tests.

All names, identifiers, events, and business rules are invented for this
sandbox. The project has no production credentials, integrations, or customer
data.

## Commands

```sh
npm test
npm run check
```
